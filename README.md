# EduGenie - Google Gemini Powered Learning Assistant

## Generative AI with Google Gemini

EduGenie is a lightweight AI-powered educational assistant that uses Google Gemini Generative AI to make learning easier and smarter.

## Features

- Smart Question & Answer
- Simplified explanations for complex concepts
- AI-generated quizzes
- Personalized learning paths
- Educational text summarization

## Technology Stack

- Python
- FastAPI
- Google Gemini AI
- HTML
- CSS

## Goal

To provide students with a simple AI-powered learning assistant that helps them understand concepts, practice through quizzes, create learning paths, and summarize educational content.
